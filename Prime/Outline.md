## Rebirth

- Reborn on Domhan
- A system RPG world
- Has a character trainer (Can change stats, skill points, skill levels)
- System limited one change per level. does stack can hold multiple changes.
- each change can affect one line of the status sheet
- ie can change vitality from 8 to 1500 or skill points from 1 to 999 or change a skill level from 1 to 20
- Max stat 1500, max skill level 20, no max skill amount
- Max level 250 
- class granted at level 10 based on skills, skill level, stats, the higher the more rare the class
- class rarity, common, uncommon, rare, epic, legendary, mythic
- stat points, per level 10, 15, 20, 25, 30, 50
- major points in class level 10, 25, 50, 100, 200
